| Border                                 | Outline                                                              |
| -------------------------------------- | -------------------------------------------------------------------- |
| Part of the CSS Box Model              | Not part of the Box Model                                            |
| Takes up space                         | Does **not** take up space                                           |
| Affects element size                   | Does not affect element size                                         |
| Can have different styles on each side | Applies to the whole element only                                    |
| Can use `border-radius`                | Usually follows the element outline but isn't part of the border box |
| Used for designing elements            | Commonly used for focus/accessibility                                |
