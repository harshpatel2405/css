Box Sizing 
----------
1. Content Box 

.container
{
    width : 400px;
    padding : 20px;
    Border : 10px solid black;
    box-Sizing : content-box;
}

The browser will think that content alone is 400 px 

Content = 400px;
padding = 20px left + 20px right = 40px
border = 10px left + 10px right = 20px

Total width of screen would be 400 + 40 + 20 = 460
